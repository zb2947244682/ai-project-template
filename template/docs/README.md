# 项目文档

项目文档按功能分为四大类，简洁清晰：

```
docs/
├── README.md        # 本文件
├── guides/          # 开发指南（环境搭建、流程规范、FAQ、故障排查）
├── specs/           # 需求规格（PRD、技术设计、调研）
├── tech/            # 技术文档（架构、API、数据库、决策记录）
└── ops/             # 运维文档（部署、测试、安全、变更日志）
```

## 目录说明

| 目录 | 用途 | 目标读者 |
|------|------|----------|
| `guides/` | 环境搭建、开发规范、常见问题、故障排查 | 全体开发人员 |
| `specs/` | 产品需求、技术设计、技术调研 | 产品经理、开发人员 |
| `tech/` | 架构图、API定义、数据库设计、架构决策 | 架构师、开发人员 |
| `ops/` | 部署流程、测试计划、安全策略、版本变更 | 运维、DevOps |

## 与 .agents/docs/ 的区别

- `docs/`：项目业务/技术文档
- `.agents/docs/`：AI 治理专用文档（各 AI 工具的使用说明）
