# 故障排查目录

本目录存放问题排查相关的文档。

## 用途

- 常见错误与解决方案
- 调试流程指南
- 日志分析方法
- 应急响应流程
- 性能问题诊断

## 实用工具

| 工具 | 说明 | 使用场景 |
|------|------|----------|
| `sessions-cleaner.bat` | 清理 AI 会话历史数据 | 当 Claude Code、Codex 或 Gemini CLI 出现性能下降、响应缓慢或需要清理历史记录时使用 |

### sessions-cleaner.bat 使用说明

位于项目根目录，双击运行即可清理以下数据：

**Claude Code**
- 全局会话历史 (`history.jsonl`)
- 会话摘要文件
- 项目级会话文件 (`*.jsonl`)
- 任务、待办、调试、文件历史等临时数据

**Codex**
- 会话目录
- 会话索引和历史文件

**Gemini CLI**
- 项目对话历史
- 临时项目数据和工具输出
- 内部对话和上下文缓存

**注意**：该工具不会删除配置、认证、内存或设置文件。
